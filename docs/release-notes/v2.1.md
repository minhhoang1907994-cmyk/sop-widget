# SOP Widget v2.1

**Ngày**: 2026-08-17
**Loại**: Minor — không có breaking change
**Trạng thái**: 🚧 **Chưa phát hành** — mã nguồn đã sửa xong, nhưng chưa build và chưa chạy thử
trên máy macOS nào. Số phiên bản trong `package.json`, `Cargo.toml`, `tauri.conf.json` vẫn là
`2.0.0`, chưa bump.
**Đặc tả**: [`../spec/sop-widget.md`](../spec/sop-widget.md) v1.4 · [`../spec/login-report-sharing.md`](../spec/login-report-sharing.md) v1.4

Bản này mở rộng app từ chỗ chỉ chạy Windows sang chạy được **cả Windows và macOS** từ cùng một
mã nguồn. Không thêm tính năng nghiệp vụ, không đổi API, không đổi schema.

---

## Thay đổi

| Hạng mục | Trước | Sau |
|---|---|---|
| Thư mục dữ liệu | Chỉ đọc `%APPDATA%`, không có thì rơi về thư mục làm việc hiện tại | Windows `%APPDATA%\NTA\SOP Widget`, macOS `~/Library/Application Support/NTA/SOP Widget` |
| Mở link báo cáo | `rundll32 url.dll,FileProtocolHandler` | Chọn theo hệ điều hành: `rundll32` (Windows) / `open` (macOS) |
| Cửa sổ trong suốt | Chỉ cần `transparent: true` | Thêm `app.macOSPrivateApi: true` + feature `macos-private-api` của crate `tauri` để có hiệu lực trên macOS |
| Icon | Chỉ có `icon.ico` | Thêm `icon.icns` và 4 tệp PNG cho bundle macOS; `icon.ico` giữ nguyên |
| Script npm | `npm run tauri` gắn cú pháp `set` của cmd | `npm run tauri` dùng chung cho macOS; bản riêng cho Windows là `npm run tauri:win` |

Chi tiết nằm ở `app_dir()` và `open_report_link` trong `src-tauri/src/lib.rs` — hai chỗ duy nhất
có mã phụ thuộc hệ điều hành.

**Người dùng Windows không bị ảnh hưởng.** Hành vi, đường dẫn dữ liệu, tệp `icon.ico` và bộ cài
NSIS đều giữ nguyên. Điểm khác duy nhất là lệnh build đổi thành `npm.cmd run tauri:win build`.

## Lưu ý khi chạy trên macOS

- **Quyền Screen Recording**: lần đầu chụp ảnh bằng chứng, macOS sẽ chặn cho tới khi người dùng
  cấp quyền ở **System Settings → Privacy & Security → Screen Recording**. Chưa cấp thì bước bắt
  buộc ảnh bằng chứng không qua được.
- **Gatekeeper**: `.app` tự build trên chính máy đó chạy thẳng được. Gửi `.dmg` sang máy Mac khác
  mà chưa code-sign + notarize thì bị chặn — người nhận phải chuột phải → Open. Ký và notarize
  cần tài khoản Apple Developer, **chưa có trong bản này**.
- **Không dùng được Mac App Store**: app bật private API để có cửa sổ trong suốt nên không nộp
  lên App Store được. Phân phối trực tiếp bằng `.dmg`.
- **Dữ liệu không dùng chung giữa hai máy**: mỗi hệ điều hành có SQLite và thư mục evidence riêng.
  Đây vẫn là dữ liệu local theo BR-20, không đồng bộ qua server.
- **Cấu hình địa chỉ máy chủ** trên macOS nằm ở
  `~/Library/Application Support/NTA/SOP Widget/server.env` — xem `../deployment.md` bước 6.

## Yêu cầu build

Mỗi bộ cài phải build trên chính hệ điều hành của nó. **Máy Windows không build được bản macOS**:
crate `objc2-exception-helper` cần compile mã Objective-C bằng clang + macOS SDK của Apple, và
đóng gói `.dmg` cần `hdiutil`/`codesign` chỉ có trên macOS.

| OS | Chuẩn bị | Lệnh |
|---|---|---|
| Windows | Rust + Microsoft C++ Build Tools | `npm.cmd run tauri:win build` |
| macOS | `xcode-select --install` (clang + linker cho `rusqlite` bundled), Rust qua rustup, Node 18+ | `npm run tauri build` |

Bản macOS build ra kiến trúc của chính máy build. Muốn một tệp chạy được cả Intel lẫn Apple
Silicon thì thêm `--target universal-apple-darwin` sau khi
`rustup target add x86_64-apple-darwin aarch64-apple-darwin`.

## Chưa kiểm chứng

Phần macOS **chưa từng được build hay chạy** — toàn bộ thay đổi làm trên máy Windows:

- Chưa build `.app`/`.dmg` lần nào; lần chạy đầu trên Mac là lần kiểm chứng thật sự
- **Chụp ảnh bằng chứng trên macOS**: crate `screenshots 0.8.10` có nhánh macOS qua
  `core-graphics 0.22.3`, nhưng chưa chạy thử. Nếu hỏng thì phương án thay là crate `xcap` —
  việc này đổi dependency, cần duyệt trước
- **Cửa sổ trong suốt + titlebar tự vẽ trên macOS**: chỉ xác nhận được bằng mắt khi chạy trên Mac
- Icon `.icns` sinh từ nguồn 256×256 nên bị phóng to lên 512, có thể không sắc nét trên màn Retina.
  Muốn nét thì cần tệp PNG 1024×1024 rồi chạy lại `npx tauri icon`

Đã kiểm được trên máy Windows: `cargo check` sạch, và các nhánh `cfg(macos)` được type-check riêng
bằng `rustc` trên một tệp trích xuất.
